# Proyecto-2-Arquitectura-de-Computadoras
Juego 2D desarrollado en lenguaje ensamblador 8086 para EMU8086. El jugador controla una nave espacial y debe esquivar meteoritos para acumular puntos, evitar colisiones y alcanzar la puntuación necesaria para ganar. Incluye menú interactivo, sistema de vidas, récord de puntuación, pausa y detección de colisiones.
